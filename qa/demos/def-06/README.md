# DEF-06 isolated demo

This standalone HTML page illustrates the overpayment defect scenario for presentation purposes only.

- It is not part of the Android app and is not connected to Firebase or any payment flow.
- The displayed negative balance is simulated locally in the browser.
- Do not use this page as evidence that the production app has the defect or that the defect was retested.

Open `index.html` in a browser and click **Simular registro del pago**. Change the amount if you want to demonstrate a different input.
